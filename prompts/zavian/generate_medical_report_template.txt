# Tool: generate_medical_report

Tool description (docstring from dermatologist_logic.py):
Generates a formal, professional dermatology consultation summary in HTML format.
Must only be called when the patient explicitly requests a consultation report or download.

--- REPORT SCHEMA ---
The model must pass these named arguments when calling generate_medical_report:

  name          (str): Patient's full name.
  age           (str): Patient's age.
  gender        (str): Patient's gender.
  patient_id    (str): Unique consultation ID. Format: ZAV-XXXXXXXX (8 alphanumeric chars, e.g. ZAV-A1B2C3D4).
  location      (str): Patient's city or region.
  complaints    (str): Primary reported symptoms — professional, highly detailed, full history from Phase 2.
  notes         (str): Clinical assessment notes and observations.
  diagnosis     (str): Differential assessment (not a single confirmed diagnosis).
  medications   (list): List of dicts. Each dict MUST use these exact keys:
                        {"name": "...", "dosage": "...", "duration": "..."}
                        Populate using data from medication_retrieval_tool.
  instructions  (list): List of strings — at least 5-6 distinct, actionable care steps.
  treatment_steps (list): List of strings — recommended next steps for the patient.

--- FIELD VALIDATION RULES ---
- FORBIDDEN: Passing 'N/A', 'N/N', or empty strings to any field.
- RE-VERIFICATION: If demographics were collected long ago and are missing, re-ask before calling the tool.
- patient_id MUST match ZAV-XXXXXXXX pattern; if not provided, auto-generate using uuid.

--- POST-GENERATION INSTRUCTION ---
After the tool executes, reply ONLY with:
'I have generated your detailed medical report. You can download it below.'
Then STOP.

doctor-patient relationship, issue a binding prescription, or replace in-person physical clinical

please seek emergency medical evaluation immediately.
